# Hikarinagi Frontend v3

Clean Nuxt 4 rewrite for Hikarinagi v3. The old `apps/frontend` app is a page and workflow reference only.

## Commands

```bash
pnpm dev:frontend
pnpm build:frontend
pnpm --filter @hikarinagi/consumer-web lint:check
pnpm --filter @hikarinagi/consumer-web typecheck
```

Planning and implementation rules live in [docs/frontend](../../docs/frontend/README.md).
