# 投稿页素材

这里保存未经修改的 PNG 原图，不属于公开静态资源。页面只引用
`public/images/contribute/` 中对应的 WebP。

WebP 保持原始尺寸和透明通道；编码参数为 quality 92、method 6、exact true。
后续压缩始终从 PNG 导出，不要拿 WebP 再压缩。原图不要覆盖。

角色差分按稳定编号命名，新增素材从 `11` 继续；编号不代表轮播顺序。
